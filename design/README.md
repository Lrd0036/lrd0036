# Cover artwork

[Open the editable Figma file](https://www.figma.com/design/lOaAGuyeuqAEIcYNOlnp8Y)

The cover is an editorial field guide to Lance Reed Dye's interests. The orbital illustration connects a terminal cube, a globe, a pen nib, and a trust shield. Text and vectors remain editable in Figma.

## Exports

The `assets/` folder contains SVG and PNG exports from Figma. The profile uses the SVG covers for sharp scaling and switches between them using the viewer's color-scheme preference. PNGs are exported at 2× for reuse. The square emblem is an optional companion graphic.

The SVG files contain outlined lettering, so viewers do not need the fonts installed. Edit the live text in Figma, then export again.

## Visual direction

- **Typography:** Fraunces SemiBold, DM Sans Regular, and IBM Plex Mono Medium.
- **Paper:** `#F3F0E7`
- **Ink:** `#152925`
- **Orange:** `#F16C45`
- **Sage:** `#C6D8B0`
- **Gold:** `#EDD18A`

The light and dark covers share the same composition. Illustration details retain dark strokes on pale surfaces for contrast.

## Update the profile

1. Edit the appropriate frame in Figma.
2. Export SVG with text outlined and PNG at 2×.
3. Replace the matching files in `assets/`.
4. Check the profile in light and dark modes.
