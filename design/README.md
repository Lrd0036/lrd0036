# Cover artwork

[Open the editable Figma file](https://www.figma.com/design/lOaAGuyeuqAEIcYNOlnp8Y)

The cover pairs display typography with an orbital diagram of Lance Reed Dye's main areas of work: a telemetry compass, a 30° isometric terminal block, a central globe, a fountain-pen nib, and a verification shield.

## Exports

The `assets/` folder contains outlined SVG plates (so viewers on GitHub do not need the fonts installed) alongside 2× PNG exports (`3200 × 1480` covers and `1600 × 1600` square emblem). The profile README switches between the light and dark SVGs via `prefers-color-scheme`, and the Zensical site in `docs/` links the same assets.
