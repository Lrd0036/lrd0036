## Exports

The `assets/` folder contains SVG and PNG exports from Figma. The profile uses the SVG covers for sharp scaling and switches between them using the viewer's color-scheme preference (or the theme toggle on this site). PNGs are exported at 2× for reuse. The square emblem serves as the companion graphic and site mark.

The SVG files contain outlined lettering, so viewers do not need the fonts installed. Edit the live text in Figma, then export again.

## Update the profile

1. Edit the appropriate frame in Figma.
2. Export SVG with text outlined and PNG at 2×.
3. Replace the matching files in `assets/` (linked automatically into `docs/assets/`).
4. Check both the GitHub profile and Zensical site in light and dark modes.
